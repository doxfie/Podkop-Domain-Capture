# Podkop Domain Capture

![OpenWrt](https://img.shields.io/badge/OpenWrt-BusyBox%20ash-00B5E2)
![Dependencies](https://img.shields.io/badge/dependencies-tcpdump--mini%20%2B%20nft-orange)
![Version](https://img.shields.io/badge/version-0.3.0--beta-blue)

Короткая SSH-утилита для OpenWrt: ловит домены, к которым обращается клиент, и помогает собрать список для добавления в Podkop.

Работает по двум источникам:

- **DNS** - лог запросов `dnsmasq`;
- **SNI** - имя сервера из TLS ClientHello, снятое с `br-lan`.

Второй источник появился потому, что одного DNS недостаточно. Устройство не покажется
в логе `dnsmasq`, если оно закешировало ответ, ходит в свой DoH/DoT в обход роутера
или у него зашит IP. Особенно этим грешат Smart TV и Android-приставки. SNI виден
в любом из этих случаев, потому что имя хоста уходит открытым текстом в самом
TLS-соединении, а не в DNS.

---

## 🚀 Быстрый запуск

Подключитесь к роутеру по SSH и выполните:

```sh
wget -O /usr/bin/pdc https://raw.githubusercontent.com/doxfie/Podkop-Domain-Capture/main/podkop-domain-capture.sh && chmod +x /usr/bin/pdc && pdc
```

Повторный запуск:

```sh
pdc
```

## 🔄 Обновления

Скрипт следит за собой сам, вручную ничего перекачивать не нужно.

**Первый запуск** ставит `tcpdump-mini`. Три попытки; если все три не удались - внятная ошибка
и выход, потому что без tcpdump основной режим не работает.

**Дальше** - не чаще раза в сутки - проверяются обновления:

- **самого скрипта** - версия в репозитории сравнивается с установленной, и если она **строго новее**, скрипт обновляется и сразу перезапускается. Именно «новее», а не «отличается»: иначе установка откатилась бы на версию из репозитория, будь она старее;
- **`tcpdump-mini`** - обновляется точечно, только этот пакет и его зависимости. Голый `apk upgrade` не вызывается никогда: на OpenWrt он потянул бы `luci`, `hostapd` и остальную систему.

Если интернета нет или GitHub недоступен, проверка молча пропускается и утилита работает
как обычно. Отметка о последней проверке лежит в `/etc/podkop-domain-capture.stamp`.

Адрес обновления можно переопределить, например для форка:

```sh
PDC_SCRIPT_URL=https://example.com/pdc.sh pdc
```

## ✨ Возможности

- выбрать одного, нескольких или всех клиентов из `/tmp/dhcp.leases`;
- собрать live-лог доменов по DNS, по SNI или по обоим источникам сразу;
- на время сбора завернуть DNS клиента на роутер и закрыть пути обхода;
- вывести уникальные домены из последнего сбора;
- отдельно показать домены, пойманные **только по SNI**, - то есть те, которых в DNS-логе не было вообще;
- вывести домены по выбранному IP клиента;
- сбросить временные логи, выключить `dnsmasq logqueries` и снять временные правила.

## 🕸 Почему одного DNS-лога мало

`dnsmasq` видит запрос, только если клиент реально спросил роутер. Типичные случаи,
когда этого не происходит:

| Ситуация | Что видно в DNS-логе | Что видно по SNI |
|---|---|---|
| Клиент закешировал ответ и идёт по сохранённому IP | ничего | домен |
| Клиент ходит в свой DoH (`8.8.8.8`, `1.1.1.1` по :443) | ничего | домен |
| Клиент ходит в DoT (:853) | ничего | домен |
| В прошивке зашит IP сервера | ничего | домен |
| Обычный запрос через роутер | домен | домен |

Поэтому режим **DNS + SNI** стоит по умолчанию.

### Временные сетевые правила

На время сбора скрипт может поднять отдельную nft-таблицу `inet pdc_capture`:

- **Перехват DNS** - `redirect` порта 53 клиента на роутер, чтобы хардкод вида `8.8.8.8` всё же попал в лог `dnsmasq`;
- **Блок DoT** - закрыть :853, чтобы клиент откатился на обычный DNS;
- **Блок QUIC** - закрыть udp:443, чтобы TLS пошёл по TCP и ClientHello был читаем.

Таблица отдельная, поэтому не задевает `fw4`, `podkop` и `zapret`, а снимается одной
командой. Скрипт удаляет её сам при `Ctrl+C` и при выходе. Если что-то пошло не так:

```sh
nft delete table inet pdc_capture
```

## 🧭 Меню

```text
---------------------------------------------------------
Podkop Domain Capture [0.3.0-beta]
Сбор DNS-доменов из dnsmasq logs для Podkop
---------------------------------------------------------

Действия
 > Собрать домены
   Показать домены из последнего лога
   Показать домены по клиенту из последнего лога
   Сбросить временные логи
   Выход
```

Клавиши:

- `↑` / `↓` - выбрать пункт;
- `Space` / `Enter` - отметить клиента;
- `Enter` - открыть пункт или подтвердить действие;
- `q` - назад или выход;
- `Ctrl+C` - остановить live-сбор.

## 🧹 Перед сбором

Ничего настраивать не нужно: выберите клиента и жмите `Enter`. По умолчанию включены оба
источника и временные правила - это рабочий вариант почти для любого устройства.

```text
---------------------------------------------------------
Сбор доменов [0.3.0-beta]
Клиенты: 192.168.1.141
---------------------------------------------------------

   Источник:  DNS + SNI
   Правила:   перехват DNS, блок DoT, блок QUIC

   Совет: перезагрузите устройство перед сбором - это сбросит его DNS-кеш.

Enter - начать   s - настройки   q - назад:
```

Единственное, что стоит сделать руками, - **сбросить DNS-кеш на самом устройстве**, иначе
оно пойдёт по сохранённым адресам. Для телевизора или приставки достаточно перезагрузки.
Команды для остальных систем и выбор отдельных источников спрятаны за `s - настройки`,
чтобы не мешать в обычном сценарии.

## 📝 Логи

Live-сбор сохраняется в:

```sh
/tmp/podkop-domain-capture.log
```

Формат строк:

```text
HH:MM:SS CLIENT_IP DOMAIN SRC
```

`SRC` - источник: `dns` или `sni`.

`dnsmasq logqueries` включается только на время сбора и автоматически выключается после остановки через `Ctrl+C`.

Пункт `Сбросить временные логи` удаляет последний live-лог и служебные файлы pdc в `/tmp`, перезапускает RAM-log роутера.

## ⚙️ Требования

- OpenWrt;
- `/bin/ash`;
- BusyBox tools;
- BusyBox `ash` с поддержкой `read -s -n 1`;
- `awk`, `sort`, `grep`, `sed`;
- `wget`.

Плюс два пакета, которые уже есть либо ставятся сами:

- **`tcpdump`** - обязателен, потому что SNI это основной источник. При первом запуске скрипт ставит `tcpdump-mini` (~385 КБ плюс `libpcap`) сам. Если не вышло за три попытки, он сообщает об ошибке и завершается: работать без него смысла нет;
- **`nft`** - для временных правил, есть в OpenWrt с `fw4` из коробки.

Проверено на OpenWrt 25.12.5 (mediatek/filogic), BusyBox 1.37, рядом работают Podkop 0.7.21 и zapret.

---

## ⚠️ Ограничения

- SNI не виден, если клиент использует **ECH** (Encrypted ClientHello). Пока встречается редко.
- Очень крупный ClientHello может не поместиться в один TCP-сегмент, тогда домен пропускается. На практике это единичные случаи.
- Захват идёт на `br-lan`, поэтому трафик самого роутера в режиме «все клиенты» исключается по IP.
